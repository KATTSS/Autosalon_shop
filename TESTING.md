## Запуск

Из корня проекта с установленными зависимостями и SECRET_KEY в .env/окружении:

```bash
autosalon_venv/bin/python -m pytest
autosalon_venv/bin/python -m pytest --shuffle-seed=20261011 --no-cov
autosalon_venv/bin/python manage.py check
autosalon_venv/bin/python manage.py makemigrations --check --dry-run
```

Можно использовать `python` из активированного окружения. HTML:
`htmlcov/index.html`; XML: `coverage.xml`. Категории выбираются через
`pytest -m unit --no-cov`, `-m integration --no-cov`, `-m scenario --no-cov`.
Порог оценивается на полном наборе, а не на отдельной категории.

заглушками, а не живыми запросами. Скриншотная проверка интерфейса, реальная
Docker-сборка и нагрузочные испытания не выполнялись.
